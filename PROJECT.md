# REZAN — Project Source of Truth

## Brand

- English: REZAN
- Arabic: ريزان
- Positioning: Luxury Niche Fragrance Maison
- Character: Quiet Luxury, Arabic Heritage, Modern Egyptian Luxury, Editorial

## Product Objective

Build a premium fragrance commerce experience that presents the maison and its story first, while remaining commerce-ready and fully navigable.

## Market Context

- Primary locale: ar-EG
- Currency: EGP / ج.م
- RTL-first Arabic experience with LTR support

## Current Delivery Mode

The project uses complete local mock/demo data until a production data source is introduced.

No backend infrastructure should be introduced without a concrete requirement.

## Core UX Priorities

- Immersive discovery
- Fragrance storytelling
- Clear navigation
- Fast product discovery
- Frictionless cart and checkout
- Mobile-first usability
- Accessibility
- Performance
